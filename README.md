# Project
# Naruto Ultimate Battle Arena

A turn-based **Naruto**-themed battle game written in pure Python.  
You fight the computer with randomly assigned characters. Each character has unique abilities, armor, status effects, and a real-time **Dodge / Counter** system.

No extra libraries required — just Python 3.

---

## Features

- **28 playable characters** (Naruto, Sasuke, Itachi, Madara, Minato, Gaara, and more)
- Unique ability sets for every character
- Combat systems:
  - Damage & armor (Susanoo, Sand Shield, Wood, etc.)
  - Burn (Amaterasu)
  - Stun (Tsukuyomi, Shadow Possession, etc.)
  - Confuse
  - Heal / regeneration
  - Power-up buffs
  - Cooldowns on heavy techniques
- **Reactable attacks** (kunai, projectiles, physical hits):
  - Press **E** to **Dodge**
  - Press **C** to **Counter**
  - You have ~2.2 seconds to react
- Simple text interface (no images needed)
- Works on Windows, macOS, and Linux

---

## Requirements

- Python 3.7 or higher
- No external packages needed
